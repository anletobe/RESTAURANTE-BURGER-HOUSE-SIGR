# Definición de la línea base — v1.0.0

## Identificación
- Proyecto: BURGER HOUSE — Sistema Integral de Gestión de Restaurante (SIGR).
- Versión: 1.0.0.
- Rama estable prevista: main.
- Herramienta de control: Git y GitHub.
- Tecnologías: HTML5 y CSS3.

## Elementos incluidos
La línea base contiene la página principal y cinco pantallas de referencia: autenticación, menú digital, pedidos, reservas y caja/reportes. También incluye README, CHANGELOG y LICENSE.

## Criterios de validación aplicables
- La estructura de archivos y carpetas está definida.
- Los enlaces de navegación entre las pantallas deben abrir los destinos correctos.
- Los estilos se cargan desde `css/styles.css`.
- Las páginas deben visualizarse en navegador de escritorio y móvil.
- La documentación técnica inicial está incluida.

## Alcance y exclusiones
Esta es una línea base de prototipo visual. Los formularios, cifras y registros son ilustrativos; no existe persistencia, autenticación real ni lógica transaccional en esta versión.

## Aprobación
- Fecha de creación: completar con la fecha real del commit inicial.
- Validado por: grupo de desarrollo.
- Responsable de aprobación: completar con el rol o integrante designado.
