## 2. Elementos incluidos

La línea base contiene la página principal y cinco pantallas de referencia correspondientes a los módulos de autenticación de usuarios, menú digital, pedidos, reservas y caja/reportes.

También incluye los archivos de estilos CSS, README, CHANGELOG, LICENSE y la documentación inicial del proyecto.

## 3. Criterios de validación

- La estructura de archivos y carpetas está definida.
- Los enlaces de navegación entre las pantallas abren los destinos correspondientes.
- Los estilos se cargan desde css/styles.css.
- Las páginas permiten visualizar el prototipo en un navegador.
- La documentación técnica inicial está incluida.
- La versión inicial está identificada mediante el tag v1.0.0 en GitHub.

## 4. Alcance y exclusiones

Esta línea base corresponde a un prototipo visual desarrollado con HTML5 y CSS3.

Los formularios, cifras y registros son ilustrativos. No existe persistencia de datos, autenticación real, conexión a bases de datos ni lógica transaccional.
