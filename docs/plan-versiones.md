
# Plan de versiones — BURGER HOUSE SIGR

## 1. Objetivo

Establecer la planificación y el seguimiento de las versiones del prototipo BURGER HOUSE — Sistema Integral de Gestión de Restaurante (SIGR), utilizando Git y GitHub como herramientas de control de versiones.

## 2. Historial de versiones

| Versión | Descripción | Estado |
|---|---|---|
| 1.0.0 | Creación de la estructura inicial y los cinco módulos del prototipo. Establecimiento de la línea base. | Completada |
| 1.1.0 | Mejoras visuales en tipografía, encabezados, botones y tarjetas de los módulos. | Completada |
| 1.2.0 | Mejoras en la presentación y organización del módulo de usuarios. | Planificada |
| 1.3.0 | Mejoras en la presentación del menú digital y sus categorías. | Planificada |
| 1.4.0 | Ajustes visuales en la pantalla de gestión de pedidos. | Planificada |
| 1.5.0 | Mejoras en las pantallas de reservas, caja y reportes. | Planificada |
| 1.6.0 | Revisión general del prototipo y actualización de la documentación final. | Planificada |

## 3. Criterios para generar nuevas versiones

Cada modificación debe realizarse sobre la rama principal o mediante el flujo de trabajo definido para el proyecto.

Los cambios deben registrarse mediante commits con mensajes descriptivos que permitan identificar su propósito.

Antes de publicar una nueva versión se debe verificar que los archivos modificados funcionen correctamente y actualizar el CHANGELOG.md.

Las versiones estables se identificarán mediante etiquetas (tags) y publicaciones (releases) en GitHub.

## 4. Herramientas utilizadas

- Git: seguimiento del historial de modificaciones.
- GitHub: almacenamiento del repositorio y administración de versiones.
- HTML5: estructura de las páginas del prototipo.
- CSS3: presentación y diseño visual.

## 5. Estado del proyecto

Actualmente se encuentran establecidas y publicadas las versiones 1.0.0 y 1.1.0.

La versión 1.0.0 corresponde a la línea base inicial y la versión 1.1.0 incorpora las primeras mejoras visuales.

Las versiones posteriores permanecen planificadas y se desarrollarán de acuerdo con las necesidades del proyecto.
